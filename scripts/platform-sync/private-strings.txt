# The guard list (ADR-0030). Two kinds of line, both case-insensitive:
#   - a regular expression: guards the application tree, apps/web, against Cloud-only code.
#     Vendor and product names are not secrets; the ADRs name them.
#   - sha256:<hex>: a confidential word as a salted hash, so the word never appears in this
#     repository. A token hashing to it fails the check anywhere in the tree, and the sync never
#     lands an upstream path containing it. Add one with
#       node scripts/platform-sync/private-strings.mjs --hash <word>
#     A hash of one word resists reading, not a determined guess: the protection is that the
#     word is not written down here.
